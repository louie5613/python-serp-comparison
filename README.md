## What You Actually Get Inside Geekflare's API Suite

Geekflare isn't just a single endpoint; it's a family of fourteen tightly integrated APIs that share **one API key** and **one credit pool**. The Search API lives at `POST https://api.geekflare.com/search` and delivers four distinct modes, each priced in **credits** that are deducted **per request**—no hidden surcharges, no per-byte fees.

| Mode | What It Returns | Credit Cost (TOTAL) |
|------|----------------|---------------------|
| **Standard web search** | Basic JSON with title, URL, snippet for the first page of Google results | 2 |
| **Full SERP JSON** (`serp: true`) | Structured JSON for page 1: organic results, ads, Google AI Overview, **People Also Ask** (questions + answers), related searches, local pack, news, images, popular products | 2 |
| **Search + scrape** (`scrape: true`) | All of the above **plus** the raw HTML of the top 1-10 result pages (JS rendering, CAPTCHA handling, anti-bot bypass included) | 4 |
| **Grounded AI answer** (`groundedAnswer: true`) | Natural-language answer generated by Google AI, with inline citations and source URLs | 5 |

All modes share the same **geo-targeting** capabilities: you can specify any of the 65,000+ cities (`city: 'Austin,Texas,United States'`) or an ISO country (`location: 'US'`). Device emulation (`device: 'desktop'` or `'mobile'`) is also supported at the same credit cost. Rich filters let you narrow by `source` (`web`, `news`, `images`), `time` (`any`, `h`, `d`, `w`, `m`, `y`, `d7`), `category` (`general`, `code`, `pdf`, `research`, `linkedin`, `wiki`), and include/exclude specific domains. Output formats include `json`, `markdown`, or `html`, making downstream processing straightforward for Python data pipelines.

Rate limits are enforced **per second** (req/s), not per concurrent connection: Free tier gets 1 req/s, Starter 5 req/s, Growth 10 req/s, Business 25 req/s, and Enterprise can scale up to 1,000 req/s. These limits are hard caps; exceeding them yields a 429 response without consuming credits.  

Because **Geekflare** runs on Google Cloud Platform behind Cloudflare, you get **99.9% uptime** backed by a globally distributed network. The platform has been bootstrapped since 2015, trusted by over 21,000 businesses, and offers a 7-day money-back guarantee if you consume less than 10% of your plan credits.

## Sending Your First Production Request to Geekflare

Below are two minimal, production-ready examples that illustrate how to call the Search API from Python and from a shell. Both use the **Free** tier's endpoint and the public **SERP Checker** tool as a target URL, so you can run them immediately without any extra setup.

### Python SDK Example

```python
# Install the official SDK first:
# pip install geekflare-api

import os
from geekflare_api import GeekflareClient

# Load your API key from an environment variable for safety
API_KEY = os.getenv("GEEKFLARE_API_KEY")
client = GeekflareClient(api_key=API_KEY)

# Build the request payload
payload = {
    "query": "python serp api tutorial",
    "serp": True,                     # Ask for full SERP JSON (includes PAA)
    "city": "Austin,Texas,United States",
    "device": "desktop",
    "output": "json"
}

# Execute the request – credits are deducted automatically
response = client.search(payload)

# The response is a dict; let's print the top organic result and the first PAA item
top_result = response["organic_results"][0]
paa = response["paa"][0] if response.get("paa") else None

print("Top result:")
print(f"  Title: {top_result['title']}")
print(f"  URL:   {top_result['link']}")
print("\nFirst People Also Ask:")
if paa:
    print(f"  Q: {paa['question']}")
    print(f"  A: {paa['answer']}")
else:
    print("  No PAA data returned.")
```

**What happens under the hood?**  
* The SDK adds the `x-api-key` header automatically.  
* The request consumes **2 credits** because `serp: true` is set and no scraping is requested.  
* If the request fails with a 5xx error, no credits are charged—Geekflare's billing policy guarantees free failed captures.  

### cURL Example

```bash
curl -X POST https://api.geekflare.com/search \
  -H "Content-Type: application/json" \
  -H "x-api-key: $GEEKFLARE_API_KEY" \
  -d '{
        "query": "python serp api tutorial",
        "serp": true,
        "city": "Austin,Texas,United States",
        "device": "desktop",
        "output": "json"
      }' | jq '.organic_results[0] | {title, link}'
```

*The `jq` filter extracts the first organic result for quick inspection.*  

Both snippets illustrate the **exact same credit consumption** (2 credits) and the same response shape, proving that the SDK is essentially a thin wrapper around the raw HTTP call.

**Practical sizing example**  
Suppose you monitor **100 keywords daily** (≈ 3,000 queries per month). A standard SERP request (2 credits) would consume **6,000 credits**. That fits comfortably inside the **Starter** tier (10,000 credits) at **$19** per month, well below the $19 monthly subscription fee.

These calculations illustrate why **credit-based pricing** is far more transparent than per-query dollar rates that fluctuate with hidden token fees. Geekflare's approach lets you budget in credits, then translate that budget into a dollar figure using the published per-credit cost for your chosen tier.

## Why So Many Teams Outgrow Their First Scraping or Data API

1. **Rate-limit ceilings** – Early-stage plans often cap at 1 req/s, which is fine for ad-hoc testing but throttles real-time monitoring. Upgrading to Growth (10 req/s) or Business (25 req/s) eliminates the bottleneck without changing code.  
2. **Credit exhaustion** – Free or Starter tiers can be exhausted quickly when you add scraping (`scrape: true`) or AI answers (`groundedAnswer: true`). Because credits reset monthly, teams that forget to monitor usage can experience sudden service pauses.  
3. **Proxy necessity** – Google increasingly blocks IPs that generate high volumes of requests. Without proxy access (available only on paid tiers) you'll see higher CAPTCHA rates, leading to failed captures and noisy data.  
4. **Feature creep** – As product roadmaps expand, teams often need local pack data, news, or image results. Geekflare's SERP mode already bundles these, whereas competitors may require separate endpoint calls or additional licensing.  
5. **Budget transparency** – Credit-based billing lets finance teams forecast spend by counting expected queries. Dollar-per-query models with hidden token fees make month-end reconciliation a nightmare.

## The Honest Bottom Line: When to Pick Geekflare vs an Alternative

**Pick Geekflare** when:  

* Your core data source is Google SERP (organic results, ads, local pack, PAA, AI Overviews).  
* You need reliable, credit-based pricing that scales predictably from a few hundred queries to millions per month.  
* You require full-page scraping with JavaScript rendering, CAPTCHA handling, and anti-bot bypass—all included in the base credit cost.  
* Uptime and SLA matter; Geekflare's 99.9% uptime and 7-day refund policy provide a safety net for production workloads.  

**Consider an alternative** when:  

* Your use case spans multiple search engines or needs deep pagination beyond page 1—SerpApi's multi-engine coverage may be worth the higher cost.  
* You're building a low-budget prototype that only needs simple keyword lookup without PAA or AI Overviews; Brave's cheap search endpoint could suffice.  

Remember that **Geekflare's limitations are explicit**: the SERP mode only targets Google and only returns the first page of results. There are no dedicated endpoints for Maps, Flights, Hotels, or Trends. If those verticals are mission-critical, you'll need to supplement Geekflare with a specialized provider.
